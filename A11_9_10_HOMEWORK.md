# A1.1 · 9–10 homework

Canonical page: `a11-9-10-ida.html`.

- 50 questions, five sections of 10, maximum two points per item (100 total).
- Controlled written answers accept explicitly curated correct variants. Case, spacing and sentence punctuation are ignored; an otherwise correct answer with a missing acute accent receives one point. `ñ` remains a different letter; single-word grammatical contrasts such as `tu` / `tú` are not treated as accent-only variants.
- Three local MP3s: one monologue, one informal dialogue, one formal dialogue. Listening distribution: 4 + 3 + 3. Scripts are original; two synthetic Spanish voices are used. All playback happens through local hosted files, with no speech-generation dependency for students.
- Listening explanations and each complete transcript unlock only after all questions for that recording are checked.
- The old part URLs redirect to the canonical page. Existing result history is preserved: submissions use the first part's original assignment key and endpoint. The portal presents the task as a single 9–10 homework and omits the obsolete second-part row from visible completion and average calculations.
- Student names continue to use `student-roster.js`. No student submissions are made by automated regression checks.
